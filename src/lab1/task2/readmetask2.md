## Задача 1: Модуль числа
### Текст задачи
Модуль числа.
Дана сигнатура метода: public int abs (int x);
Необходимо реализовать метод таким образом, чтобы он возвращал модуль
числа х (если оно было положительным, то таким и остается, если он было
отрицательным – то необходимо вернуть его без знака минус).

Пример 1:
x=5
результат: 5

Пример 2:
x=-3
результат: 3

### Алгоритм решения
1. Метод принимает целое число `x`.
2. Используется условный оператор `if` для проверки: является ли переданное число отрицательным (`x < 0`).
3. Если условие выполняется (число меньше нуля), метод меняет знак числа на противоположный (с помощью выражения `-x`) и возвращает полученное положительное значение.
4. Если условие ложно (число больше либо равно нулю), условный блок пропускается, и метод возвращает само число `x` без изменений.

## Задача 2: Безопасное деление
### Текст задачи
Безопасное деление.
Дана сигнатура метода: public double safeDiv (int x, int y);
Необходимо реализовать метод таким образом, чтобы он возвращал деление x
на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. При
делении на 0 следует вернуть из метода число 0. Подсказка: смотри
ограничения на операции типов данных.

Пример 1:
x=5 y=0
результат: 0

Пример 2:
x=8 y=2
результат: 4

### Алгоритм решения
1. Метод принимает два целых числа: делимое `x` и делитель `y`.
2. В первую очередь используется условный оператор `if` для проверки делителя: `if (y == 0)`.
3. Если `y` равно нулю, метод немедленно завершает работу и возвращает значение `0`, избегая критической системной ошибки деления на ноль (`ArithmeticException`).
4. Если `y` не равно нулю, выполняется деление. Учитывая особенность языка Java (деление `int` на `int` отбрасывает дробную часть), делимое предварительно приводится к вещественному типу с помощью `(double) x`. Это обеспечивает точное математическое вычисление.
5. Метод возвращает корректный результат деления типа `double`.

## Задача 3: Тридцать пять
### Текст задачи
Тридцать пять.
Дана сигнатура метода: public bool is35 (int x);
Необходимо реализовать метод таким образом, чтобы он возвращал true, если
число x делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то
вернуть надо false. Подсказка: оператор % позволяет получить остаток от
деления.

Пример 1:
x=5
результат: true

Пример 2:
x=8
результат: false

Пример 3:
x=15
результат: false

### Алгоритм решения
1. Метод принимает целое число `x`. Возвращаемый тип в сигнатуре исправлен с `bool` на корректный для Java `boolean`.
2. Для определения делимости используется операция получения остатка от деления (`%`). Если `x % N == 0`, число делится на `N` нацело.
3. В первую очередь используется условный оператор `if` для проверки самого строгого ограничения: делится ли число одновременно и на 3, и на 5 (`x % 3 == 0 && x % 5 == 0`). Если да (например, число 15), метод возвращает `false`.
4. Если первая проверка пройдена, выполняется вторая проверка: делится ли число хотя бы на одно из них (`x % 3 == 0 || x % 5 == 0`). Если да, метод возвращает `true`.
5. Во всех остальных случаях (если число не делится ни на 3, ни на 5) метод возвращает `false`.

## Задача 4: Строка сравнения
### Текст задачи
Строка сравнения.
Дана сигнатура метода: public String makeDecision (int x, int y);
Необходимо реализовать метод таким образом, чтобы он возвращал строку,
которая включает два принятых методом числа и корректно выставленный
знак операции сравнения (больше, меньше, или равно).

Пример 1:
x=5 y=7
результат: “5< 7”

Пример 2:
x=8 y=-1
результат: “8 >-1”

Пример 3:
x=4 y=4
результат: “4==4”

### Алгоритм решения
1. Метод принимает два целых числа: `x` и `y`.
2. Используется конструкция условных операторов `if-else if-else` для перебора трех возможных вариантов сравнения.
3. Сначала проверяется условие `x > y`. Если оно истинно, метод конкатенирует (склеивает) значения переменных и строковый литерал `" > "` с помощью оператора `+`, после чего возвращает полученную строку. В Java при сложении строки с числом, число автоматически преобразуется в текст.
4. Если первое условие ложно, проверяется `x < y`. При истинности возвращается строка со знаком `" < "`.
5. Если оба предыдущих условия ложны (что означает равенство чисел), срабатывает блок `else`, и метод возвращает строку со знаком `" == "`.

## Задача 5: Тройной максимум
### Текст задачи
Тройной максимум.
Дана сигнатура метода: public int max3 (int x, int y, int z);
Необходимо реализовать метод таким образом, чтобы он возвращал
максимальное из трех полученных методом чисел. Подсказка: идеальное
решение включает всего две инструкции if и не содержит вложенных if.

Пример 1:
x=5 y=7 z=7
результат: 7

Пример 2:
x=8 y=-1 z=4
результат: 8

### Алгоритм решения
1. Метод принимает три целых числа: `x`, `y` и `z`.
2. Внутри метода инициализируется целочисленная переменная `max`, которой изначально присваивается значение первого параметра `x`. Мы условно принимаем его за максимальное на старте.
3. Используется первая конструкция `if`, которая проверяет: больше ли второе число `y`, чем текущее значение `max`. Если условие истинно, переменной `max` присваивается значение `y`.
4. Далее идет вторая, независимая конструкция `if` (без `else` и без вложенности). Она проверяет: больше ли третье число `z`, чем текущее значение `max`. Если условие истинно, переменной `max` присваивается значение `z`.
5. По итогам этих двух последовательных проверок в переменной `max` гарантированно оказывается самое большое число из трех. Метод возвращает значение переменной `max`.
